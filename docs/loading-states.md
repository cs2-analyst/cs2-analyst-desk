# 桌面统一加载反馈

2026-10-25：按产品确认方案实现。沿用 Fluent UI v9，只调整桌面任务进度与展示，不改变确定性分析、归档格式或报告数据语义。

## 反馈规则

| 场景 | 行为 |
| --- | --- |
| 选择 DEM、归档或导出位置 | 原生文件选择器负责交互；应用内不重复转圈 |
| DEM 解析、生成分析、保存归档 | 同一个任务对话框显示文件 basename、真实阶段、可用的取消操作；10 秒后显示已用时间，不估计百分比或剩余时间 |
| 导入时选择自己 | 同一对话框切换为输入步骤，停止进度动画，提交期间防止重复操作；Escape 不默默提交选择 |
| 归档导入／导出 | Main 报告真实校验／写入阶段；提交后按现有规则打开比赛 |
| 比赛库首次读取 | 表头和骨架行占位，未知总数为 `—` |
| 筛选、排序、分页 | 保留旧列表，固定反馈区域标记更新并弱化旧内容；禁用旧行操作，允许继续调整查询；失败保留结果并可重试 |
| 打开／删除比赛 | 对应行反馈，内容位置稳定；详情无报告时提供恢复骨架和失败重试 |
| 磁盘占用 | 底部局部占位，刷新保留已有统计 |
| 回放首帧／跳转／跨块 | 根据目标块是否缺失判断等待；地图局部提示、玩家和事件占位；已有画面明确为上一帧 |
| 热力图初始读取／刷新 | 首次统计骨架；后续保留完整上次结果及其筛选说明；本批所有图层完成后统一发布，错误在对应区域重试 |

反馈通常延迟 200ms 出现，视觉反馈可延续到 400ms 最小时长；已完成的数据、操作锁和会话从不等待反馈定时器。任务结束时可短暂显示完成／取消反馈，随后自动收起。

任务使用 Fluent Dialog 的 non-modal 模式，工作区临时 `inert`，遮罩从 40px 标题栏下开始。标题栏不属于受限工作区，窗口按钮仍可点击和键盘聚焦；对话框没有无实际作用的关闭按钮。

## 生命周期与边界

- `report-contract` 仅增加展示进度：`saving`、可选 DEM basename、归档 `validating`／`writing`。Renderer 不接触绝对路径、文件句柄或分析模块。
- 原导入 Promise 负责取消完成，取消 IPC 返回不代表 worker／staging 已清理。保存尾段不承诺取消；晚进度、重复取消、已结束任务的身份提交不能重启任务。
- Renderer 递增任务身份隔离晚提交；终态清除取消标记，后续归档任务不会继承取消提示。
- Main 互斥、候选会话提交和失败保留规则不变；缩小反馈范围不会放开冲突的数据操作。
- 回放旧预取只填充有界缓存，不能关闭新目标等待或恢复错误回合。等待时保留 Canvas 上一帧，不画伪造位置。
- 热力图快照绑定 session、底图 URL、完整 scope、分辨率和启用图层；等待期间使用旧快照自己的底图与坐标规则。renderer-wide 两个真实并发请求上限及 generation 校验保持。
