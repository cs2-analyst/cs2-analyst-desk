# L5 · 本地比赛库最终验收矩阵（执行前冻结）

> 状态：待 L3/L4 PASS 后执行。本文是验收清单，不是通过结论；未执行项必须记 NOT RUN，不得用 L1/L2 证据替代。

## 1. 前置

- main 集成 L3、L4 且两者独立复核 PASS。
- 全量 Desktop 测试、类型检查、构建通过；生产 NSIS 与 test-seam NSIS 均由最终 main 构建。
- 所有验收使用归属明确的临时 LOCALAPPDATA/安装目录，不触碰用户已有安装或比赛库。
- 版本号不变；P8 不启动。

## 2. 矩阵

| # | 场景 | 方法 | 通过条件 |
| --- | --- | --- | --- |
| 1 | 生产安装/卸载 | 生产 NSIS 静默安装到自有目录，启动、导入 Dust2、重启、卸载 | 安装/卸载成功；比赛库在卸载后保留；注册项清理 |
| 2 | 开发/测试 seam 数据操作 | test-seam 安装版：导出 .cs2a、删除、导入、无 DEM 打开 | 报告/热力图/Replay 哈希一致；失败不影响现有比赛 |
| 3 | 升级 | 先装 L2 基线安装包并导入比赛，再覆盖安装最终包 | 旧归档可列出、可无 DEM 打开；不重复/不损坏 |
| 4 | 回滚 | 卸载最终包、重装 L2 基线，确认旧归档仍在 | 旧版本遇到新格式时明确降级/拒绝，不静默改写 |
| 5 | 损坏/恶意包 | 截断、尾随、路径穿越、超限、SHA 不符、未知版本 | 有界失败；现有比赛仍可打开；无 staging 残留 |
| 6 | 删除 | 单条、批量、删除活动比赛、模拟删除失败 | 索引/文件/容量一致；活动会话先释放；失败可报告 |
| 7 | 大库首屏 | 隔离副本模拟 50+ 条目录，不声明为真实比赛 | 首屏只读小索引，不全量解压 Chunk |
| 8 | 性能 | 冷启动列表、打开归档、随机 Chunk、热力图筛选 | 记录 p50/p95/峰值；Replay 5s 历史债单独标注 |
| 9 | 隐私/网络 | 检查生产包无上传路径；离线运行核心流程 | 无 DEM/个人证据自动上传；导出前提示隐私 |
| 10 | 键盘/高对比度 | Tab 顺序、禁用态、forced-colors | 可操作、可辨识；未测项记 NOT RUN |
| 11 | DPI/物理多屏 | 125%/150%、跨屏拖动 | 能测则记录；不能测记 NOT RUN，不声称 PASS |
| 12 | 人工验收 | 产品负责人实际打开、切换、导出/导入 | 需真实人工确认；代理不得代签 |
